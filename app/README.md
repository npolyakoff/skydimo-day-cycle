# Редактор расписания HyperHDR

Откройте `index.html` в браузере. Установка зависимостей и сервер не нужны.

Поле «Адрес HyperHDR» задаёт нужный инстанс, по умолчанию `http://localhost:8099/`. Можно изменить порт или IP/имя компьютера. `/json-rpc` добавляется автоматически (готовый адрес с этим путём тоже принимается). Адрес сохраняется в браузере отдельно от JSON-расписания и встраивается во все скачиваемые EXE и PowerShell-скрипты. После изменения адреса скачайте программу заново и замените старую. Неверный адрес блокирует скачивание с пояснением ошибки.

Кнопка «Скачать EXE» открывает небольшое диалоговое окно: укажите адрес HyperHDR, выберите обычный или тестовый вариант, настройте значок трея и нажмите «Скачать». Адрес из этого окна применяется также при скачивании PowerShell. Кнопки «Отмена», «×» и Escape закрывают окно без скачивания.

В приложении два раздела: «Настройки» с редактором расписания и «Как запускать» с пошаговой инструкцией по запуску скачанного скрипта. Переключение разделов сохраняет введённые настройки и останавливает проигрывание предпросмотра при переходе к инструкции.

- Нажмите на свободное место графика или перетаскивайте вертикальную линию, чтобы выбрать время. Точное время также можно ввести в поле «Выбранное время». Выбор времени останавливает проигрывание и сам по себе не меняет расписание.
- Под графиком задайте яркость и цвет, затем нажмите «Применить к этому времени». Приложение добавит точки на выбранную минуту или обновит существующие без дубликатов.
- Добавляйте отдельные точки яркости и цвета кнопками «+ Точка» и «+ Цвет». Перетаскивайте точки яркости или задавайте точное время и процент в списке под графиком.
- Задавайте цвета и время в разделе «Палитра дня». Между цветами используется плавная интерполяция RGB (smoothstep), между уровнями яркости — линейная.
- Передвигайте ползунок времени или проиграйте сутки за 24 секунды. Предпросмотр работает только на экране.
- Настройки автоматически сохраняются в браузере, если доступно локальное хранилище. Используйте экспорт и импорт JSON для переноса или резервной копии.
- Скачайте PowerShell-скрипт, чтобы применить расписание к HyperHDR. Исходные скрипты репозитория не изменяются.

Кнопка «Скачать EXE» создаёт `HyperHDR-DayCycle.exe` со встроенным текущим скриптом. Переключатель «Показывать значок в трее» (по умолчанию включён) сохраняется в браузере и встраивается при скачивании EXE. Для изменения режима уже работающей программы её нужно остановить и скачать EXE заново. EXE запускает Windows PowerShell без окна; если значок включён, выход доступен через меню значка → `Exit`. В обоих режимах остановка доступна из PowerShell в папке с EXE: `.\HyperHDR-DayCycle.exe --stop`. Команда останавливает оболочку и дочерний PowerShell в текущем сеансе примерно за секунду. Не завершайте только родительский EXE принудительно: дочерний PowerShell может продолжить работу.

Нужны Windows PowerShell 5.1 и .NET Framework 4.x. EXE не подписан. Рабочий PS1 временно сохраняется в `%LOCALAPPDATA%\HyperHDR-DayCycle`; политика выполнения `Bypass` применяется только к дочернему процессу. Одновременно допускается одна EXE-оболочка в текущем сеансе пользователя; другие контроллеры нужно остановить отдельно.

Для автозапуска сохраните EXE в постоянную папку и поместите ярлык на него в папку, открываемую командой `shell:startup`. В приложении есть подробная инструкция. Для обновления завершите EXE через трей или командой `--stop`, замените файл новой загрузкой и запустите заново. Не включайте одновременно автозапуск EXE и старой задачи PowerShell.

Исходник оболочки: `scripts/HyperHDR-DayCycle-Launcher.cs`. После его изменения пересоберите браузерный шаблон:

```powershell
powershell.exe -NoProfile -File .\scripts\HyperHDR-BuildLauncher.ps1
```

Сборка использует установленный компилятор .NET Framework, без загрузки пакетов. Генерируется `app/launcher-template.js`; этот файл должен лежать рядом с `index.html`. Браузер добавляет к PE-файлу UTF-8 скрипт, его длину (uint32 little-endian) и маркер `HHDRPS01`. Старый VBS-запускатель больше не используется: для автозапуска нужен ярлык на скачанный EXE.

В каждом расписании должно оставаться минимум две точки с разным временем. Последняя точка переходит в первую через полночь. Для плоского участка укажите одинаковые значения на его концах.

Вариант скачивания «Тестовый — сутки за 24 секунды» создаёт `HyperHDR-DayCycle-Test.exe`. Он управляет реальным HyperHDR по текущим точкам редактора: с виртуального 00:00, один час за одну секунду, с повторением суток и интервалом обновления 50 мс (плюс время запроса). Виртуальное время рассчитывается по Stopwatch, поэтому задержки запросов не накапливают отставание расписания. Из `tests/HyperHDR-DayCycle-Test.ps1` взят принцип ускорения, а не его отдельная кривая яркости. Для остановки: `.\HyperHDR-DayCycle-Test.exe --stop` или меню трея. Обычную версию перед тестом нужно остановить. PowerShell-кнопка по-прежнему экспортирует обычный суточный скрипт. Настройка трея применяется к обоим вариантам EXE.

Скачанный `HyperHDR-CustomCycle.ps1` запускается в Windows PowerShell 5.1 или новее:

```powershell
powershell.exe -NoProfile -File .\HyperHDR-CustomCycle.ps1
```

Перед запуском включите HyperHDR и остановите другие контроллеры. Адрес `http://localhost:8099/json-rpc`, приоритет `50` и интервал обновления `1` секунда находятся в начале скачанного скрипта. Остановка — `Ctrl+C`. Скрипт обновляет цвет с ограниченным сроком действия и пытается очистить свой приоритет при завершении.

Начальное расписание повторяет `scripts/HyperHDR-DayCycle.ps1`. Яркость умножается на каждый канал RGB; нулевая яркость даёт чёрный цвет. Браузерный предпросмотр иллюстративный: внешний вид реальных светодиодов зависит от оборудования и калибровки.
