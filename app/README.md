# Редактор расписания HyperHDR

Откройте `index.html` в браузере. Сервер, Node.js и установка пакетов для работы редактора не нужны. Рядом с HTML должны оставаться `style.css`, `theme.js`, `app.js`, `live-control.js` и `launcher-template.js`.

Тумблер в шапке переключает светлую и тёмную тему. По умолчанию оформление соответствует системе и меняется вместе с ней. Ручной выбор сохраняется в браузере. Оформление не влияет на цвет реальной подсветки.

## Настройки и подключение

В разделе «Настройки» на основном экране укажите адрес HyperHDR. По умолчанию — `http://localhost:8099/`. Можно изменить порт, IP или имя компьютера; адрес с `/json-rpc` тоже принимается. При открытии страницы выполняется одна автоматическая проверка по сохранённому адресу. Кнопка «Проверить подключение» повторяет её вручную.

Проверка отправляет только `serverinfo` через WebSocket на том же порту (HTTP → WS, HTTPS → WSS). Она не меняет цвет, не запускает контроллер и закрывает соединение после ответа. Результат показывает ответ API и время запроса, ошибку авторизации или таймаут 5 секунд. Браузер может запросить доступ к локальной сети; для WSS нужен доверенный сертификат. Ссылка «Открыть HyperHDR» открывает веб-интерфейс. Ответ API не подтверждает физическое состояние светодиодов.

Изменение адреса сбрасывает результат проверки и останавливает проигрывание. Новый адрес применяется к следующим подключениям и скачиваемому EXE. Уже запущенный EXE нужно остановить и заменить новой загрузкой.

## Редактор расписания

- Нажмите на график или перетаскивайте вертикальную линию для выбора времени. Точное время можно ввести в поле «Выбранное время».
- Задайте яркость и цвет под графиком и нажмите «Применить к этому времени». Существующие точки обновятся, недостающие добавятся без дубликатов.
- Кнопки «+ Точка» и «+ Цвет» добавляют отдельные точки. Точки яркости можно перетаскивать, время и значения — редактировать в полях списка.
- Между цветами используется RGB smoothstep, между уровнями яркости — линейный переход. Последняя точка переходит в первую через полночь. В каждом расписании остаётся минимум две точки с уникальным временем.
- Настройки автоматически сохраняются в локальном хранилище этого браузера. Пресетов, JSON-файлов настроек и их импорта/экспорта нет. «Сбросить» возвращает исходные точки расписания.

Начальное расписание повторяет `scripts/HyperHDR-DayCycle.ps1`. Яркость умножается на каналы RGB; нулевая яркость даёт чёрный цвет. Внешний вид подсветки зависит от светодиодов и калибровки.

## Проигрывание на реальной подсветке

Остановите другие контроллеры, затем нажмите «Проиграть сутки». Приложение отправляет текущие значения цвета и яркости в HyperHDR: 1 виртуальный час за 1 секунду, начиная с выбранного момента и с повторением суток. Используется приоритет `50`.

«Пауза», ручной выбор времени, смена адреса, скрытие вкладки и переход к разделу «Как запускать» останавливают проигрывание и отправляют `clear`. При потере связи проигрывание останавливается с ошибкой. Последняя команда цвета истекает через 1,5 секунды, если очистка не доставлена. Автоматического переподключения нет. Ползунок времени без запущенного проигрывания сам по себе цвет устройству не отправляет.

## Скачивание и запуск EXE

Нажмите «Скачать EXE», настройте «Показывать значок в системном трее» и подтвердите скачивание. Кнопки «Отмена», «×» и Escape закрывают диалог без скачивания. Файл `HyperHDR-DayCycle.exe` содержит текущее расписание и адрес и управляет светом по локальному времени компьютера. Отдельного ускоренного EXE нет: для быстрой проверки используется проигрывание в браузере. Кнопка скачивания PowerShell временно скрыта, её реализация сохранена.

После скачивания нажмите правой кнопкой на EXE → «Свойства» → «Общие» → «Разблокировать» → «Применить» → «ОК». Если пункта нет, этот шаг не нужен. Затем включите HyperHDR, остановите другие контроллеры и запустите EXE двойным щелчком.

Нужны Windows, Windows PowerShell 5.1 и .NET Framework 4.x. EXE запускает вложенный скрипт без окна PowerShell; браузер после запуска EXE можно закрыть. Файл не подписан цифровой подписью.

Если значок трея включён, остановка доступна через меню значка → `Exit`. В обоих режимах используйте PowerShell в папке с EXE:

```powershell
.\HyperHDR-DayCycle.exe --stop
```

Команду выполняйте из той же учётной записи и сеанса Windows. Оболочка и дочерний PowerShell останавливаются примерно за секунду; последняя команда цвета истекает примерно через 4 секунды. В новой версии EXE родитель и PowerShell объединены Windows Job Object: принудительное завершение EXE завершает и дочерний процесс. Связь устанавливается до запуска PowerShell; при ошибке её создания контроллер не запускается. Для этой возможности старый EXE нужно заменить новой загрузкой.

Рабочий PS1 создаётся в `%LOCALAPPDATA%\HyperHDR-DayCycle` и удаляется при обычном выходе. `ExecutionPolicy Bypass` задаётся только для дочернего процесса. EXE-оболочка допускает один экземпляр в текущем сеансе; другие PowerShell-контроллеры и браузерное проигрывание остановите отдельно.

## Автозагрузка и обновление

Сохраните EXE в постоянную папку. Нажмите Win+R, введите `shell:startup` и создайте в открывшейся папке ярлык на EXE. Автозапуск HyperHDR включите отдельно. EXE может запуститься раньше HyperHDR, но его встроенный скрипт ждёт успешного ответа `serverinfo` на настроенном адресе и порту. Просто открытый порт или ответ другого HTTP-сервера не запускают управление. Интервал ожидания — 2 секунды после завершения запроса, таймаут запроса — 3 секунды. До готовности команды цвета и очистки не отправляются. После ошибки управления скрипт снова ждёт API и затем рассчитывает цвет по текущему времени, без проигрывания пропущенного участка.

Для обновления остановите EXE, скачайте новое расписание и замените файл по прежнему пути. Существующий ярлык продолжит работать. Для отмены автозапуска удалите ярлык. Изменения редактора не передаются уже работающему EXE автоматически.

Для принудительной остановки откройте Диспетчер задач (Ctrl+Shift+Esc) → «Подробности», нажмите правой кнопкой на `HyperHDR-DayCycle.exe` → «Завершить задачу» (или «Снять задачу»). Новый EXE автоматически завершает дочерний PowerShell через Windows Job Object; отдельный пункт завершения дерева не требуется. Чтобы отключить последующий запуск, в разделе «Автозагрузка приложений» выберите программу → «Отключить». Чтобы удалить запись, удалите её ярлык из `shell:startup`; используйте этот способ и если записи нет в Диспетчере задач. Отключение автозапуска само по себе не останавливает работающую программу. Эти действия описаны также в свёрнутом блоке раздела «Как запускать».

Раздел «Как запускать» в приложении содержит три основных шага: скачать EXE, разблокировать файл в свойствах и запустить.

## Сборка и проверки для разработки

После изменения `scripts/HyperHDR-DayCycle-Launcher.cs` выполните из корня проекта:

```powershell
powershell.exe -NoProfile -File .\scripts\HyperHDR-BuildLauncher.ps1
```

Команда использует установленный компилятор .NET Framework без загрузки пакетов и обновляет `app/launcher-template.js`. Не редактируйте этот файл вручную. Браузер добавляет к PE-шаблону UTF-8 скрипт, его длину (uint32 little-endian) и маркер `HHDRPS01`. Начальный комментарий `HyperHDR-ShowTray` задаёт режим трея. Изменения HTML/CSS/JS сборки не требуют.

Node.js нужен только для автоматических проверок из корня проекта:

```powershell
node tests/HyperHDR-Connection-Test.js
node tests/HyperHDR-LiveControl-Test.js
node tests/HyperHDR-Exe-Test.js
powershell.exe -NoProfile -File .\tests\HyperHDR-Startup-Test.ps1
powershell.exe -NoProfile -File .\tests\HyperHDR-Job-Test.ps1
```

Они не управляют реальными светодиодами. Job-тест компилирует консольный процесс, запускает безобидный PowerShell с ожиданием и проверяет завершение обоих процессов после принудительной остановки родителя. Внешний вид интерфейса, работу трея, автозапуск и реальную подсветку проверяйте отдельно.
