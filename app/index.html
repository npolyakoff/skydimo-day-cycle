Как запускать

Настройте свет в редакторе, затем запустите расписание на компьютере с HyperHDR.

Запуск EXE и добавление в автозагрузку

Для быстрой проверки выберите в настройках вариант «Тестовый — сутки за 24 секунды» и нажмите «Скачать EXE». Файл HyperHDR-DayCycle-Test.exe повторяет текущее расписание редактора на реальной подсветке: каждый час длится 1 секунду, обновления происходят примерно каждые 50 мс, цикл начинается с 00:00. Скорость может снижаться при медленном ответе HyperHDR. Перед запуском остановите обычный контроллер: тестовая и обычная EXE-версии не запускаются одновременно в одном сеансе.

Тест останавливается через трей → «Exit» или командой .\HyperHDR-DayCycle-Test.exe --stop. Настройка значка в трее действует и на тестовую версию. Для постоянной автозагрузки скачивайте обычный вариант EXE.

  1. Скачайте настроенный EXE

    В разделе «Настройки» нажмите «Скачать EXE». Файл HyperHDR-DayCycle.exe уже содержит текущее расписание. Сохраните его в постоянную папку, например C:\HyperHDR.

  2. Запустите и проверьте

    Перед скачиванием выберите «Показывать значок в трее». Включите HyperHDR, остановите другие контроллеры и откройте EXE двойным щелчком. Окно PowerShell не появится. Если переключатель был включён, значок «HyperHDR Day Cycle» будет в трее, в том числе среди скрытых значков рядом с часами; выход — правой кнопкой → «Exit». Если выключен, программа будет видна только среди процессов в Диспетчере задач. Повторный запуск не создаёт ещё один контроллер в текущем сеансе Windows.

  3. Добавьте ярлык в автозагрузку

    Нажмите Win + R, введите shell:startup и нажмите Enter. В открывшейся папке создайте ярлык на сохранённый HyperHDR-DayCycle.exe: правая кнопка → «Создать» → «Ярлык» → выберите EXE. Сам EXE оставьте в постоянной папке.

    При следующем входе в Windows программа запустится автоматически. Включите автозапуск HyperHDR отдельно. Если HyperHDR ещё не запущен, контроллер продолжит попытки соединения.

Чтобы обновить расписание или режим трея, остановите программу, скачайте новый EXE и замените старый файл по тому же пути. Ярлык продолжит работать. Для отмены автозапуска удалите ярлык из shell:startup. Изменение переключателя на странице не влияет на уже запущенный EXE.

Как остановить EXE без значка в трее

Откройте PowerShell в папке с EXE и выполните команду. Она работает в обоих режимах и завершает оболочку вместе с дочерним PowerShell; обработка занимает около секунды.

.\HyperHDR-DayCycle.exe --stop

Для произвольного пути используйте & "C:\HyperHDR\HyperHDR-DayCycle.exe" --stop. Команду выполняйте из той же учётной записи и сеанса Windows, где запущена программа. После остановки можно заменить EXE. Последняя команда цвета истекает примерно через 4 секунды.

EXE запускает вложенный скрипт через Windows PowerShell и требует .NET Framework 4.x. Рабочая копия скрипта создаётся в %LOCALAPPDATA%\HyperHDR-DayCycle и удаляется при обычном выходе. Политика выполнения задаётся только для дочернего процесса; системные настройки не меняются. При выходе последняя команда цвета истекает примерно через 4 секунды.

Как найти запущенный EXE?

Найдите процесс HyperHDR-DayCycle.exe в разделе «Подробности» Диспетчера задач. Его дочерний процесс — powershell.exe, который выполняет файл %LOCALAPPDATA%\HyperHDR-DayCycle\schedule-….ps1. Если значок трея включён, он также доступен рядом с часами. Для остановки используйте команду .\HyperHDR-DayCycle.exe --stop или меню трея → «Exit», чтобы завершить оба процесса. Принудительное завершение только процесса EXE в Диспетчере задач может оставить дочерний PowerShell работающим.

Файл не подписан цифровой подписью: Windows или браузер могут показать предупреждение. Если EXE завершился с ошибкой, скачайте PowerShell-версию и запустите её в видимом окне по инструкции ниже. Выберите один способ автозапуска: ярлык EXE или задачу Планировщика.

Справка Microsoft об автозагрузке Windows.

  1. Настройте расписание

    В разделе «Настройки» выберите время на графике, задайте яркость и цвет и нажмите «Применить к этому времени». Проверьте переходы с помощью предпросмотра.

  2. Скачайте скрипт

    Нажмите «Скачать PowerShell» в настройках. Сохраните файл HyperHDR-CustomCycle.ps1 в удобную папку. Он содержит ваше текущее расписание.

  3. Включите HyperHDR

    Запустите HyperHDR и остановите другие скрипты управления подсветкой: используйте один контроллер за раз.

    В настройках редактора укажите адрес нужного инстанса HyperHDR. По умолчанию это http://localhost:8099/; путь /json-rpc добавляется автоматически. Для другого порта или компьютера измените адрес перед скачиванием EXE или PowerShell. Адрес также находится в начале скачанного скрипта вместе с приоритетом 50 и интервалом обновления 1 секунда.

  4. Запустите в PowerShell

    Откройте папку со скачанным файлом в терминале и выполните команду. Нужен Windows PowerShell 5.1 или новее.

    powershell.exe -NoProfile -File .\HyperHDR-CustomCycle.ps1

    Оставьте окно PowerShell открытым — скрипт непрерывно выбирает цвет по локальному времени компьютера. Для остановки нажмите Ctrl + C.

Автозапуск через Планировщик Windows

Настройте запуск при входе в свою учётную запись Windows. Сначала убедитесь, что скачанный скрипт работает при ручном запуске.

  1. Сохраните файл в постоянную папку

    Например, C:\HyperHDR\HyperHDR-CustomCycle.ps1. Это пример пути: если выберете другую папку, укажите её и в параметрах задачи ниже.

  2. Создайте задачу

    Нажмите Win + R, введите taskschd.msc и нажмите Enter. Справа выберите «Создать задачу…». На вкладке «Общие» задайте имя HyperHDR Day Cycle и выберите «Выполнять только для зарегистрированного пользователя». Оставьте свою учётную запись; повышенные права для этого скрипта не требуются.

  3. Добавьте триггер

    На вкладке «Триггеры» нажмите «Создать…», выберите «При входе в систему» и свою учётную запись. Установите задержку 30 секунд, чтобы HyperHDR успел запуститься, и убедитесь, что триггер включён. Отдельно включите автозапуск самого HyperHDR.

  4. Укажите действие

    На вкладке «Действия» нажмите «Создать…» → «Запуск программы». Заполните три поля:

    Программа или сценарий:

    C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe

    Добавить аргументы:

    -NoProfile -NonInteractive -WindowStyle Hidden -File "C:\HyperHDR\HyperHDR-CustomCycle.ps1"

    Рабочая папка (без кавычек):

    C:\HyperHDR

    Если Windows установлена на другом диске, скорректируйте путь к PowerShell. Путь к скрипту в аргументах оставьте в кавычках — это позволяет использовать папки с пробелами.

  5. Разрешите непрерывную работу

    На вкладке «Параметры» снимите флажок «Останавливать задачу, выполняемую дольше…»: скрипт должен работать постоянно. Разрешите запуск задачи по требованию. Для уже выполняющейся задачи выберите «Не запускать новый экземпляр».

    Если подсветка должна работать на ноутбуке от батареи, на вкладке «Условия» снимите ограничения на запуск и остановку при питании от батареи.

  6. Проверьте запуск

    Сохраните задачу, остановите вручную запущенный контроллер и в библиотеке Планировщика нажмите правой кнопкой на задачу → «Выполнить». Проверьте подсветку. Состояние «Выполняется» ожидаемо: цикл не завершается сам. Окно PowerShell будет скрыто.

    Для проверки автозапуска выйдите из Windows и войдите снова; дождитесь задержки запуска. Если подсветка не меняется, проверьте журнал задачи и повторите ручной запуск скрипта в видимом окне, чтобы прочитать ошибки.

Чтобы остановить фоновый скрипт, выберите задачу → «Завершить». Чтобы отменить автозапуск — «Отключить». При принудительном завершении очистка приоритета может не выполниться; последняя команда цвета истечёт примерно через 4 секунды.

Если вы изменили расписание

Остановите запущенный скрипт, скачайте новую версию из настроек и запустите её той же командой. Для автозапуска завершите задачу в Планировщике, замените файл по указанному в задаче пути и нажмите «Выполнить». Изменения в браузере не передаются работающему скрипту автоматически.

Сохранение и перенос настроек

Редактор сохраняет изменения в этом браузере. Для резервной копии используйте «Экспорт JSON», для восстановления — «Импорт JSON» в разделе «Настройки».

Страница показывает предпросмотр и не отправляет команды устройству. При ошибке соединения проверьте, что HyperHDR работает и адрес в скрипте соответствует его настройкам.
