# skydimo-day-cycle

Скрипты PowerShell для автоматического управления подсветкой через HyperHDR. Проект создаёт суточный цикл освещения: цвет плавно меняется от тёплого ночного к прохладному дневному и обратно, а ночью яркость снижается.

Скрипты отправляют RGB-команды в HyperHDR через HTTP JSON-RPC. Основной цикл ориентируется на локальное время компьютера и работает, пока запущен процесс PowerShell.

## Как работает суточный цикл

Цвет плавно меняется между контрольными точками:

| Время | Цвет RGB |
| --- | --- |
| 01:00 | Тёплый оранжевый — `255, 65, 18` |
| 07:00 | Холодный белый — `220, 235, 255` |
| 13:00 | Голубой — `75, 175, 255` |
| 19:00 | Тёплый свет — `255, 170, 85` |
| 23:00 | Тёплый оранжевый — `255, 65, 18` |

С 01:00 до 06:00 яркость составляет 50%, с 06:00 до 07:00 постепенно возрастает до 100%. До полуночи сохраняется полная яркость, затем к 01:00 она снижается до 50%. Яркость применяется к значениям RGB перед отправкой.

## Структура проекта

Редактор расписания находится в [app/index.html](app/index.html). Откройте его в браузере: он позволяет настроить цвет и яркость, скачать обычный или ускоренный тестовый EXE и выбрать режим трея. Инструкции по запуску и автозагрузке доступны в разделе «Как запускать» и в [описании приложения](app/README.md). Старый `Start-HyperHDR.vbs` не требуется.

```text
scripts/HyperHDR-DayCycle.ps1       # Основной суточный цикл
tests/HyperHDR-DayCycle-Test.ps1   # Ускоренный просмотр: сутки за 24 секунды
app/                              # HTML-редактор и шаблон скачиваемого EXE
scripts/HyperHDR-DayCycle-Launcher.cs # Исходник EXE-оболочки
scripts/HyperHDR-BuildLauncher.ps1 # Пересборка шаблона EXE для приложения
tests/HyperHDR-Exe-Test.js         # Проверка экспорта EXE без обращения к подсветке
examples/HyperHDR-SetRed.ps1        # Однократное включение красного на 5 секунд
AGENTS.md                         # Руководство для участников проекта
```

Ускоренный просмотр использует собственное расписание яркости и служит для визуальной проверки переходов. Тесты выполняются вручную и управляют реальной подсветкой.

## Требования и запуск

- Windows PowerShell 5.1 или новее.
- Запущенный HyperHDR с настроенной подсветкой и доступным JSON-RPC по адресу `http://localhost:8099/json-rpc`.

Сборка и установка дополнительных библиотек не требуются. Из корня проекта запусти основной цикл:

```powershell
powershell.exe -NoProfile -File .\scripts\HyperHDR-DayCycle.ps1
```

Для ускоренного просмотра:

```powershell
powershell.exe -NoProfile -File .\tests\HyperHDR-DayCycle-Test.ps1
```

Запускай один контроллер за раз: скрипты используют одинаковый приоритет `50`. Для остановки нажми `Ctrl+C`. Для автозапуска скачанного EXE создай ярлык в папке `shell:startup`, как описано в приложении.

## Настройка

В начале основного скрипта можно изменить `$Url` (адрес HyperHDR), `$Priority` (приоритет команд), `$UpdateSeconds` (интервал проверки времени, по умолчанию 1 секунда) и `$Points` (время и RGB контрольных точек). Расписание яркости задаётся в функции `Get-Brightness`.

Если HyperHDR работает на другом устройстве, замени `localhost` его адресом в нужном скрипте. Ошибки подключения и отклонённые команды выводятся в консоль.
