# HyperHDR Day Cycle

Приложение для настройки цвета и яркости подсветки HyperHDR в течение суток.

## Как открыть приложение

Скачайте репозиторий на компьютер и откройте ярлык [HyperHDR-DayCycle.lnk](HyperHDR-DayCycle.lnk) в его корневой папке. Приложение откроется в браузере. Для управления подсветкой запустите HyperHDR.

## Разделы приложения

- **Настройки** — адрес и проверка подключения к HyperHDR, график яркости, цвета по времени суток, проигрывание расписания на реальной подсветке и скачивание настроенного EXE.
- **Как запускать** — скачивание, разблокировка и запуск EXE, настройка автозапуска, принудительная остановка программы и отключение автозагрузки.
